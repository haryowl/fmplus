Embed host example

The iframe is the dashboard. This parent page only passes vehicle context and an opaque tenant key k. The GpsGate token stays on the dashboard server (tenants.json / ARMADA_AUTH_HEADER) and is never put in the iframe URL or in postMessage.

  • Query: ?embed=1&k=&appId=&groupId=&userId=&from=&to=&tz=&period=
  • Optional live update: { type: "fms-embed:set", groupId, userId, from, to }
  • Parents: https://armada.id and any https://*.armada.id subdomain
